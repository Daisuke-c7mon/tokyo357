アプリごとのよくある質問

シメキリ逆算

「今日やる分」が 0 になります

その曜日の作業時間が 0 分に設定されている可能性があります。原稿の編集画面 →「1日に使える作業時間」で、平日と土日、または曜日ごとの時間を確認してください。すべての曜日が 0 分だと逆算できません。

すでに今日のぶんを記録し終えている場合も 0 になります（「達成」と表示されます）。

実測ペースに切り替わりません

切り替わるのは、「進んだ量」と「かけた時間」の両方が入った記録が 2 単位ぶん溜まってからです。「+1ページ」ボタンだけで記録している場合はかけた時間が見積り値のままなので、記録シートから実際にかかった時間を入れてください。

いまどちらで計算しているかは、原稿の詳細画面に「実測ペース」または「見積りペース」として表示されます。

機種変更でデータを引き継ぎたい

設定 →「バックアップを書き出す」→「書き出したファイルを共有」で JSON ファイルを保存し、新しい端末で 設定 →「バックアップを読み込む」から選んでください。読み込みは既存のデータを消さずに追加します。

このアプリは iCloud 同期を搭載していません。同期の不具合で記録が壊れる経路をはじめから作らないためです。

立て直し案を適用したあと、元に戻せますか

戻せます。適用されるのは原稿の設定（締切・作業時間・総量・1単位あたりの時間）だけなので、編集画面から手で戻してください。記録が消えることはありません。複数の案を組み合わせて適用してもかまいません。

集中タイマーを動かしたままアプリを閉じてしまいました

計測は続いています。開始時刻を保存して差を取る方式なので、アプリを閉じても、強制終了しても止まりません。次に開いたときに「終了して記録」を押すと、その時間が記録されます。

「道具箱」を消したい

設定 →「おすすめ（道具箱）を表示する」をオフにすると、タブごと表示されなくなります。アプリの機能に制限はかかりません。

追加の課金はありますか

ありません。120円の買い切りで、購入した時点からすべての機能が使えます。原稿の数も記録の数も無制限で、サブスクリプションもアプリ内課金もありません。

禁酒ウォッチ

禁酒を始めた日時を間違えて登録しました

設定 → 禁酒の開始日時 から、いつでも直せます。「昨日の夜が最後だった」なら、その時刻を入れておくと本数や金額の計算も正確になります。

飲んでしまいました。記録は消えてしまいますか

消えません。ホーム画面の「飲んでしまった」から記録すると、そこまでの連続記録が履歴に保存され、累計の禁酒時間・最長記録・挑戦回数はそのまま残ります。その場から仕切り直す形になります。きっかけを1つ選んでおくと、記録タブの「曜日別の危険度」に反映され、次に備えやすくなります。

節約できた金額やカロリーはどう計算していますか

最初に登録した「1日の本数」と「1本の値段」に、飲まずにいる日数（小数）を掛けています。カロリーは純アルコール1gあたり7kcal、糖質1gあたり4kcalで算出し、純アルコール量は「容量(ml) × 度数(%) ÷ 100 × 0.789」で求めています。体脂肪換算は7,200kcal＝1kgとした概算です。いずれも一般的な換算式による目安で、実際の増減は食事や運動によって変わります。

飲む量が変わりました。あとから変更できますか

設定 → 飲んでいたお酒 から、種類・1日の本数・1本の値段を変更できます。変更後は、それまでの経過時間に新しい単価が適用されて再計算されます。

ウィジェットが表示されない／更新されません

ホーム画面を長押し → 左上の「＋」→「禁酒ウォッチ」から追加してください。ロック画面はロック画面を長押し →「カスタマイズ」から追加できます。時計の部分は常に進みますが、金額やカロリーはiOSが決めたタイミングで更新されるため、数分ずれることがあります。アプリを開くと即座に最新になります。

機種変更のときにデータを引き継げますか

設定の「iCloudで同期」をオンにしておくと、同じApple IDの端末に記録が引き継がれます。オフのままだと端末内にのみ保存され、アプリを削除すると復元できません。当社側にデータをお預かりしていないため、こちらから復元することもできません。

通知が届きません

iPhoneの 設定 → 通知 → 禁酒ウォッチ で通知が許可されているかご確認ください。そのうえでアプリの 設定 から「達成の通知」「毎日のふりかえり」をオンにしてください。集中モードがオンの時間帯は届かないことがあります。

「おすすめ」タブの商品は何ですか

ノンアルコール飲料や炭酸水など、禁酒を続けている方が使っているものを紹介しています。タップすると外部サイト（Amazon）の検索結果が開きます。当社が販売するものではなく、効果・効能を保証するものでもありません。

やめてから体調が悪いのですが

長く多量に飲まれていた方が急に断酒すると、手のふるえ・発汗・強い不安・けいれんなどの離脱症状が出ることがあり、まれに生命に関わります。本アプリは医学的な助言を行うものではありません。症状がある場合はアプリの記録より優先して、医療機関にご相談ください。お住まいの自治体の保健所・精神保健福祉センターでも相談を受け付けています。

広告や課金はありますか

ありません。アプリ内広告、アプリ内課金、サブスクリプションのいずれも入っていません。

オセロ

ゲームの進行状況（解放したレベル）が消えました

進行状況は端末の中だけに保存しています。アプリを削除すると一緒に消え、再インストールしても元には戻りません。機種変更のときも引き継がれません。サーバーに預かっていないため、こちらから復元することもできません。

次のレベルが選べません

レベルは1つ勝つごとに次が開きます。引き分けと敗北では解放されません。まずは現在のレベルで勝ってください。

コンピュータが強すぎます／弱すぎます

レベル1は必ず勝てる練習台（ランダムに打ちます）、レベル10は先読みの全力です。強さはレベル選択画面でいつでも変えられます。負けても解放済みのレベルが下がることはありません。

自分の番なのに石が置けません

相手の石をタテ・ヨコ・ナナメのいずれかで挟める場所にしか置けません。置ける場所は盤面に印が出ます。印が1つも出ていない場合は自動でパスになり、相手の番に移ります。

広告や課金はありますか

ありません。アプリ内広告、アプリ内課金、サブスクリプションのいずれも入っていません。

個人情報は集めていますか

集めていません。通信を行わず、アカウント登録もありません。詳しくはプライバシーポリシーをご覧ください。

対応している端末を教えてください

iOS 16以降のiPhoneとiPadです。オフラインで動作します。
