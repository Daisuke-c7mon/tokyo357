# アフィリエイト素材（A8.net 出稿用）

株式会社サウナ（Sauna Inc.）が配信している iOS アプリの、広告素材一式です。
`tools/build_affiliate.py` が `tools/apps.py` の台帳から自動生成しています。
**このフォルダのファイルを手で直さないでください。**アプリ名や価格を変えるときは
`tools/apps.py` を直して、生成し直します。

```bash
python3 tools/build_affiliate.py
```

## 中身

アプリごとに `affiliate/<slug>/` があり、次が入っています。

| ファイル | 中身 |
|---|---|
| `banner-300x250.png` | レクタングル（大）。もっとも使われるサイズ |
| `banner-728x90.png` | ビッグバナー。PCの記事上部・下部 |
| `banner-468x60.png` | レギュラーバナー |
| `banner-160x600.png` | スカイスクレイパー。実際の画面を下に入れています |
| `banner-320x100.png` | スマートフォン用 |
| `banner-200x200.png` | 正方形。サイドバー用 |
| `banner-120x60.png` | マイクロバナー |
| `text.md` | テキスト広告の文面（文字数つき） |
| `info.md` | 案件情報。提携メディアに見せる訴求点と注意点 |

すべて Chrome のヘッドレスで生成しています。外部サービスは使っていません。

## 先に確認しておくべきこと

出稿の前に、**この2点で成立するかを判断してください。**あとから設計を変えるのは大変です。

### 1. App Store のダウンロードは成果地点にできない

A8 の成果は「広告主のサイトに置いた成果地点のタグが発火する」ことで計上されます。
ところが **App Store でのダウンロードは、Apple から A8 に通知が飛びません。**
Apple の旧アフィリエイトプログラム（PHG）は2018年にアプリ向けの提供を終了しています。

つまり「ダウンロードされたら報酬」という成果条件は、**そのままでは計測できません。**

対応として、自社ドメインに中継ページを用意しました。

```
https://tokyo357.com/go/<slug>
  → App Store（?ct=a8 付き）へ転送
```

このページに A8 の成果地点タグを貼れば、**App Store に送り出した時点で成果が立ちます。**
実質的にはクリック成果です。ファイルは `go/<slug>.html` で、
`<!-- A8_CONVERSION_TAG -->` のコメント位置にタグを貼ってください。
貼る作業は `tools/build_go.py` の `PAGE` テンプレート側に入れると、再生成しても消えません。

なお `ct=a8` は App Store Connect の App Analytics でキャンペーンとして集計されます。
A8 の計上数と、Apple 側の実際のダウンロード数を**両方見て突き合わせる**ことができます。
最初の1か月はここを必ず確認してください。

### 2. 120円のアプリで、報酬が成立するか

売上120円に対して、Apple の手数料（小規模事業者プログラムで15%）を引くと、
手取りはおよそ **102円**です。ここから A8 の報酬とシステム利用料を払うことになります。

A8.net には広告主としての初期費用と月額費用がかかります（金額は A8 に直接ご確認ください）。
**1本あたり102円の手取りで、その固定費を回収できる本数が出るか**を先に計算してください。

現実的な選択肢は次のどれかです。

1. **全アプリをまとめて1案件にする** — 固定費を19本で分担する
2. **クリック成果・低単価で数を集める** — 1件あたり数円〜数十円
3. **買い切り以外の入口を作ってから出稿する** — 現状の単価では成立しないと判断する

私（開発側）としては、いまの単価では **3 が正直なところ**だと考えています。
ただし、認知そのものに価値があるという判断であれば 1 が現実的です。
このあたりは事業判断なので、数字だけ置いておきます。

## 提携メディアに伝えること

`info.md` に各アプリ分を書いていますが、共通するのは次の3点です。

### 書いてよいこと

- **価格を必ず書く。**「無料」と読める書き方をしない
- 広告が入っていないこと
- 実際の画面は `https://tokyo357.com/apps/<slug>` に掲載しています。引用可

### 書かないでほしいこと

- **「1位」「No.1」などの順位表記。** 順位は日々変わり、根拠を示せない表示は
  景品表示法上のリスクになります。当社のサイトでは、実測した日付とセットでしか順位を出していません
- 効果や結果の断定（「必ず〜できる」「絶対に〜」）
- 他社アプリを名指しでけなす表現。事実にもとづく比較は問題ありません

### なぜここを厳しくするか

アフィリエイターが掲載した広告の表示について、**責任を負うのは広告主**です。
2023年10月から、いわゆるステルスマーケティングは景品表示法の規制対象になっています。
提携メディアには「広告であることを明示する」よう、提携条件に明記してください。

## バナーの作り直し

アプリを追加したとき、価格を変えたときは、次を順に実行します。

```bash
python3 tools/build_shots.py       # 各アプリのリポジトリから画面を取り込む
python3 tools/build_affiliate.py   # バナー・テキスト・案件情報を作り直す
python3 tools/build_go.py          # 中継ページを作り直す
```

`build_affiliate.py` は `assets/shots/<slug>/01.jpg` があれば
160x600 のバナーに実際の画面を入れます。無ければ文字だけになります。
