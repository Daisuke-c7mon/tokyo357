しずかTL for X

Safari で X（旧 Twitter）を読むときの表示を、あなた側で決めるための拡張機能です。おすすめの差し込み・トレンド・反応数・購読の勧誘を隠し、フォロー中の投稿を流れてきた順に読めます。

なぜ作ったか

この種の拡張機能はすでにいくつもあります。よくできたものも多い。それでも使った人の不満は、機能の少なさではなく、いつも同じ一点に集まっていました。

「入れたのに、変わらない」

そして厄介なのは、その原因がユーザーには一切見えないことです。実際には次のどれかが起きています。

  1. そもそも拡張機能が一度も動いていない。Safari の設定で拡張機能がオフのまま、あるいはサイトへのアクセスが「許可」になっていない。iOS の設定は階層が深く、途中で止まっていても何も表示されません。
  2. 動いてはいるが、その項目だけ効いていない。サイト側の作りが変わり、隠す対象を見つけられなくなっている状態です。
  3. ホーム画面に追加した Web アプリの中で開いている。iOS の仕様上、この場合はどの Safari 拡張機能も動きません。

どれであっても、画面の上では「何も変わらない」という同じ見え方になります。だからユーザーは「このアプリは効かない」と結論を出して消します。解くべきなのは隠す項目の数ではなく、この見分けがつかない状態のほうだと考えました。

しずかTLがやること

拡張機能が実際に走るたび、端末の中に稼働記録が残ります。アプリの診断画面はそれを読んで、「一度も動いていない」のか「動いてはいるが、この項目だけ効いていない」のかを切り分け、必要な設定画面まで案内します。原因の分からない“無言の不発”をなくすための仕組みです。

さらに、サイト側の作りが変わって項目が効かなくなったときは、アプリが「反応なし」と表示します。セーフモードをオンにしておけば、ゆるい判定へ自動で切り替えて動き続けます。静かに壊れたまま放置されない、というのがこのアプリの設計方針です。

できること

  • 3タップで終わるプリセット — 「時系列だけ」（フォロー中の投稿を流れてきた順に）、「しずかに見る」（数字・トレンド・勧誘を消す）、「集中（文字だけ）」（画像も動画も止める）の3つ。細かく決めたい方のために、12項目の個別スイッチも用意しています。
  • 診断画面 — 拡張機能が動いているか、どの項目が効いていないかを端末内の稼働記録から判定し、直すべき設定画面まで案内します。
  • セーフモード — 仕様変更で項目が効かなくなったとき、ゆるい判定へ自動で切り替えて動き続けます。
  • 時間帯で自動切り替え — 平日9–18時は文字だけ、23時以降はしずかに、休日はそのまま。曜日と時間でプリセットを変えられます。判定は端末の中だけで行われ、通信は発生しません。
  • 押しつけない — 自分で「おすすめ」タブを選んだときは勝手に戻しません。ツールバーから「60分だけ元の表示に戻す」がすぐ押せます。
  • 表示を変えるだけ — 投稿の削除、自動操作、アカウント連携は一切行いません。ログインもしません。
  • 広告なし・追加課金なし — 買い切り120円で、購入した時点からすべての機能が使えます。

使いはじめる前に

Safari 拡張機能は、インストールしただけでは動きません。次の2つが必要です。アプリを開くと、この手順を画面の指示に沿って進められます。

  1. iPhone の 設定 → アプリ → Safari → 機能拡張 で「しずかTL」をオンにする
  2. 同じ画面で x.com / twitter.com へのアクセスを「許可」にする（「確認」のままだと毎回止まります）

設定が終わったら、Safari で x.com を開き直してください。うまく動かないときは、アプリの診断画面を開けば、どこで止まっているかが表示されます。

ホーム画面に追加したアイコンからだと動きません

これは仕様です。iOS では、ホーム画面に追加した Web アプリの中でどの Safari 拡張機能も動作しません。しずかTLに限った話ではなく、Apple 側の制限です。

お手数ですが、Safari のアプリから x.com を開いてご利用ください。

プライバシー

このアプリは個人情報を一切収集しません。ログイン不要、アカウント連携なし、解析SDKなし、外部送信なし。設定はすべてこの端末の中だけに保存されます。投稿の内容を読み取って外部に送ることもありません。App Storeの「App のプライバシー」でも、すべての項目を「データを収集しません」として申告しています。

詳しくはプライバシーポリシーをご覧ください。

ENGLISH

QuietTL — a calmer, chronological way to read

QuietTL is a Safari extension that puts you back in charge of how your feed looks. Hide algorithmic suggestions, trends, engagement counts and subscription upsells, and read posts from the accounts you follow in the order they arrived. What makes it different is that you can tell whether it is working.

  • Requires iOS 17.0 or later. iPhone and iPad.
  • One-time purchase. No ads, no in-app purchases, no subscriptions.
  • Three presets — In order, Quiet, and Focus (text only) — plus twelve individual switches.
  • A real diagnostic: every run leaves a local record, and the Diagnose screen separates "it has never run" from "it runs, but this one rule stopped matching," then walks you to the exact setting you need.
  • When the site changes and a rule stops matching, the app flags it as "no match." Safe Mode switches that rule to a looser check so it keeps working.
  • Schedules by time and weekday, evaluated entirely on device.
  • It only changes how pages look — no automation, no account access, no posting.
  • No personal data is collected. No sign-in, no analytics SDK, no network requests.

Before you start: enable the Safari extension and set x.com / twitter.com access to "Allow" (the app guides you). Note that iOS does not run any Safari extension inside Home Screen web apps — open the site in Safari itself.
