Xの画像や動画を止めて、文字だけで読みたいとき

動画が勝手に再生される、画像に目を取られて読み進められない。Xの公式設定で止められる範囲と、それ以上に文字だけで読みたいときの方法を整理します。

先に結論

動画の自動再生だけなら、X自体の設定で止められます。ただしこれは「勝手に再生しない」だけで、画像や動画のサムネイルはそのまま表示されます。画像も含めて文字だけで読みたい場合は、X の公式設定ではできず、表示を変える仕組み（Safari 拡張機能など）が必要です。

X の設定でできること — 動画の自動再生を止める

X には、タイムラインに流れてきた動画を自動で再生するかどうかを選ぶ設定があります。執筆時点では、設定とプライバシー → アクセシビリティ、表示、言語 → データ利用の設定の中に「動画の自動再生」の項目があり、「しない」を選ぶと自動では再生されなくなります。メニューの名前や場所は X 側の更新で変わることがあるので、見つからないときは設定画面の検索で「自動再生」と入れて探してください。

同じ画面には、画像や動画の読み込みを軽くする「データセーバー」の項目がある場合もあります。これは通信量を抑えるための設定で、画像が低画質で読み込まれるようになりますが、画像そのものが消えるわけではありません。

この設定はアカウントや端末ごとに保存されるため、公式アプリとブラウザの両方で使っている場合は、それぞれで確認しておくと確実です。

公式の設定で止まらないもの

  • 画像。写真や画像付きの投稿は、自動再生の設定に関係なく表示されます。
  • 動画のサムネイル。再生はされなくても、最初のコマは画像として表示されます。
  • GIF。GIF が動画と同じ扱いで止まるかどうかは、表示する場所や更新の時期によって変わることがあります。

つまり公式の設定は「音や動きで気を取られない」ための設定であって、「画面から画像をなくす」設定ではありません。作業中に文字だけ追いたい、画像に目が行って読み進められない、という悩みには足りないことがあります。

文字だけで読みたいとき

画像・動画を画面から外して読みたい場合は、X の表示そのものを書き換える必要があります。iPhone・iPad で Safari から X を開いているなら、Safari 拡張機能で表示を変える方法があります。

しずかTLの「集中（文字だけ）」プリセットは、この用途のためのものです。画像と動画を止め、投稿の文字だけを追えるようにします。表示を変えるだけなので、投稿やアカウントには何も手を加えません。一時的に画像を見たいときは、ツールバーから「60分だけ元の表示に戻す」ですぐ戻せます。

時間帯で切り替える

文字だけで読みたいのは、たいてい仕事中や勉強中など決まった時間帯です。常に文字だけにしてしまうと、休みの日に写真を見たいときに毎回戻す手間がかかります。

しずかTLでは、曜日と時間でプリセットを切り替えられます。たとえば「平日9〜18時は文字だけ、それ以外はそのまま」のように決めておけば、切り替えを意識せずに済みます。判定は端末の中だけで行われ、通信は発生しません。考え方は時間帯で表示を変えるの記事でも説明しています。

効く範囲に注意

  • Safari 拡張機能は、X の公式アプリには効きません。表示を変えられるのは Safari で x.com を開いているときだけです。
  • ホーム画面に追加した X のアイコンから開いた場合も効きません。iOS の仕様で、ホーム画面の Web アプリ内ではどの Safari 拡張機能も動作しないためです（詳しくはこちら）。
  • 入れたのに画像が消えないときは、拡張機能が動かないときに確認する順番で設定を確認してください。しずかTLではアプリの診断画面で、動いていないのか、一部の項目だけ効いていないのかを確認できます。

まとめ

動画が勝手に流れるのを止めたいだけなら、X の「動画の自動再生」を「しない」にするのが手軽です。画像も含めて文字だけで読みたいなら、Safari で X を開き、表示を書き換える拡張機能を使います。必要な時間帯だけ文字だけにしておくと、見たいときに見られないという不便も避けられます。
